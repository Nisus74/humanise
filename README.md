# humanise

An open source agent skill that makes AI-generated writing sound more human. Works across Claude Code, Codex, Google Antigravity (Gemini CLI), and other AI coding agents.

## What it does

`humanise` can be invoked in two ways:

- **Rewrite mode** — paste in existing AI-generated text and the agent rewrites it to sound more natural and human
- **Guide mode** — invoke before writing to have the agent apply human-sounding style from the start
