# Dialect: en-US (US English)

Spelling and idiom essentials. Switching logic: `../cultural-calibration.md`. Matching regex: `US_ENDINGS` in `writing_checks.py`.

**Spelling**

- -ize, -or, -er, single -l-: organize, color, center, traveling, modeling
- catalog / dialog / analog; judgment; program (all uses); practice (noun + verb); license (noun + verb)

**Idiom and units**

- two weeks (not fortnight), in the hospital, different than/from, math (not maths)
- imperial in customer-facing content; USD default; Oxford comma by default
- double quotes for speech, punctuation inside the quotes

**Register**

- Leans more formal in writing. State capability directly; AU/UK self-deprecation reads as weakness, so drop it. "Cheers" as a sign-off reads British/Australian; avoid.
