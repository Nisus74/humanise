# Channels: <your name>

The engine ships a full set of channel playbooks (`references/channel-playbooks.md`) plus a nearest-neighbour mapping for anything unlisted. You usually don't need to touch them.

Use this file only to:

- List the channels you actually write in, so the skill leads with them.
- Override a playbook where your habit differs from the default (e.g. "I close board papers on the ask, not a summary").

Keep it short. The engine's defaults are sensible; this is for your exceptions, not a rewrite.
